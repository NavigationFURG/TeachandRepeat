Repeat Method based on Waypoint Following
=========================================

1. Overview
-----------
The Waypoint Following repeat method allows a robot to traverse a path learned during the **Teaching** phase by utilizing the ROS 2 Navigation Stack (`Nav2`). This approach effectively performs the repeat method by communicating directly with an active Nav2 bringup, treating each recorded pose as a sequential waypoint.

By leveraging the powerful components and configurations available in Nav2, the robot navigates through the recorded points using standard (or custom!) local planners and controllers. This adds robustness to the repeat phase since it takes advantage of Nav2's capabilities, including obstacle avoidance, smooth velocity control, and recovery behaviors. Which, of course, all of them can be customized by the user to fit their specific robot and environment.

2. Architecture and How it Works
--------------------------------
The core of this method resides in the ``nodes/navigate_through_poses.py`` file. The script operates as follows:

1. **Path Reading**: The node reads a saved path file (e.g., ``TEST_PATH_ORIENTED.txt``) located inside the ``path_saves/`` directory. This file contains the coordinates (x, y, yaw) that were previously generated by the ``teach_path_coords.py`` node.
2. **Data Conversion**: The text-based coordinates are parsed using an utility function and converted into an array of oriented ``PoseStamped`` messages.
3. **Communication with Nav2**: Using the Nav2 Simple Commander API (``BasicNavigator``), the script validates that the Navigation 2 stack is fully active (``waitUntilNav2Active()``) and prepares the connection to the Nav2 action server.
4. **Waypoint Execution**: The poses are sent to Nav2 via the ``goThroughPoses()`` API. Nav2 is then tasked with orchestrating the robot's movement sequentially through all the provided points. During navigation, the node continually gets feedback and handles task progression.
5. **Path Visualization**: A continuous line-strip marker is periodically published to the topic ``teach_and_repeat/repeat/bezier_marker`` so users can visually inspect the intended route inside RViz.

3. Node Configuration and Setup
-------------------------------
For this method to work correctly, the user must provide an active Nav2 pipeline configured specifically for their robot, complete with proper AMCL/localization, global maps, costmaps, and a controller.

3.1. Node Parameters
~~~~~~~~~~~~~~~~~~~~

When starting the ``navigate_through_poses.py`` node, you can configure the following parameters:

**path_file**
  Type: string
  Default: ``'TEST_PATH_ORIENTED.txt'``

  The filename of the trajectory coordinates stored inside the ``path_saves/`` folder.

**frame_id**
  Type: string
  Default: ``'map'``

  The reference frame for the waypoints. Generally, this matches the global fixed frame of your localization system.

3.2. Prerequisites for the User
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

1. Maintain an active map or odometry frame.
2. Launch a fully functioning Nav2 stack configured for your robot's kinematics.
3. Explicitly set the robot's initial pose (e.g., via RViz 2D Pose Estimate) aligning it with the map before repeating the path.
4. Ensure the chosen path file exists in the ``path_saves/`` directory.
