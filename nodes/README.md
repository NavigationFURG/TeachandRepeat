This is the folder where the main nodes from the code are from. You must be thinking: "Hey, why is there a repeat_path_coords node, if there isn't a single citation of it in the documentation?" The answer is that repeat_path_coords is a node that we used during the development of the package to test the path the following process of our DWA-based approach WITHOUT the Bézier curves, and it is not intended for use by end-users considerind that repeat_bezier_path does the same, but with more features overall. We decided that this node should stay so that users can have a better understanding of how the development went and also to provide a more simple way to test the home-made DWA controller without the need of using the Bézier curve implementation, if so desired.

The other nodes are respective to the guides shown in documentation:
- navigate_through_poses: This node is used in the "Repeat Guide using Waypoint Following (Nav2)" guide, and it is responsible for transforming the coordinates from the path demonstration into waypoints that can be followed using Nav2's navigation stack.
- repeat_bezier_path: This node is used in the "Repeat Guide using Bézier Curves" guide, and it is responsible for implementing the path following process using Bézier curves to smooth the path and improve the robot's navigation performance.
- teach_path_coords: This node is used in the "Teach Guide" and it is responsible for recording the robot's path during the teaching phase, saving the coordinates into a file that can later be used for path following.
- turtle_teleop: This node is used as a alternative to the teleop_twist_keyboard in the "Teach Guide" and it allows the user to teleop the robot using the keyboard, which is a common method for demonstrating a path during the teaching phase.

Much of the code in Bézier approach is from the [original author](https://github.com/jardeldyonisio/teach_and_repeat), and we've have made some modifications to adapt it to our needs and to integrate it with the rest of the package. Visit the original repo for more info!
